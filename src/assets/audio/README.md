# 🎹 主题音乐

## 放入你的钢琴曲

把 MP3 文件放到这个目录，命名为 `theme.mp3`：

```
src/assets/audio/theme.mp3
```

重启 dev server，音乐就会在所有模式中播放。

## 推荐曲目

- **Summer Motivation** (Pixabay 免费)
  https://pixabay.com/music/solo-piano-summer-motivation-444129/

## 每个模式的听感

同一首曲子，不同模式听起来不同：

| 模式 | 效果 |
|------|------|
| AWAKE | 原调，轻柔 |
| SLEEP | 降半音，高频滤除（像隔着被子听） |
| DREAM | 升半音，高音通透，最空灵 |
| MEMORY | 原调，温暖 |
| CAPTURE | 极低音量，很闷 |
| DEEP_SLEEP | 降全音，几乎只剩嗡鸣 |

## 没有文件时

自动使用内置钢琴和弦合成，不需要任何文件。
